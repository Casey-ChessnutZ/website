# Publishing checklist

- [ ] Required Event title and unique slug are filled in.
- [ ] Every linked event and asset is published before its Landing Page.
- [ ] The `home` Landing Page has the intended section order.
- [ ] Homepage, event listing, and `/events/[slug]` have been checked in preview.
- [ ] Optional fields have been checked both populated and empty.
- [ ] Preview is opened through the secured Contentful preview URL and displays the draft-preview notice.
- [ ] Exiting preview returns the site to published Delivery API content.
- [ ] Metadata title and description are appropriate for sharing.
